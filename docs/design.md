# AI 语音绘图工具 — 设计文档

**日期**: 2026-06-12
**场景**: 比赛作品（暑期夏令营）
**原则**: 纯语音控制，零鼠标/键盘介入

---

## 1. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | React + TypeScript | 生态成熟，Canvas 库配合好 |
| Canvas 引擎 | Fabric.js | 对象模型、交互态、序列化内置 |
| 语音识别（主） | Web Speech API | 零成本、浏览器原生、实时 |
| 语音识别（兜底） | 云端 STT（阿里云/讯飞/Whisper API） | 低置信度结果重识别，保证准确率 |
| NLU | LLM API（OpenAI GPT / Claude） | 自然语言理解 + 指令分解 + 上下文维护 |
| TTS 反馈 | Web Speech Synthesis API | 浏览器原生，零成本 |
| 构建 | Vite | 快 |

---

## 2. 整体架构

```
┌──────────────┐    ┌─────────────────┐    ┌──────────────────┐
│  语音输入层   │ →  │   NLU Agent 层   │ →  │    绘图引擎       │
│  Web Speech  │    │  LLM + 画布状态  │    │  Canvas + 状态管理 │
│  + 云端兜底   │    │  + 对话历史      │    │  + 操作执行        │
└──────────────┘    └─────────────────┘    └──────────────────┘
                           ↓                       ↓
                    ┌─────────────────┐    ┌──────────────────┐
                    │   反馈层         │ ←  │   状态管理层      │
                    │  TTS + 视觉高亮  │    │  元素列表/撤销栈   │
                    └─────────────────┘    └──────────────────┘
```

**数据流**: 麦克风 → STT 文本 → LLM（含画布状态+历史）→ 操作序列 JSON → Canvas 执行 → 状态更新 → 反馈

## 3. 语音输入层

### 3.1 双通道设计

- **主通道**: Web Speech API, `continuous: true`, `lang: zh-CN`, 取 `final` 结果
- **兜底通道**: 置信度 < 0.7 时送云端 STT 重识别，3s 超时降级用低置信度结果
- **触发方式**: 页面麦克风按钮（触摸友好）+ 可选唤醒词「小画小画」

### 3.2 交互延迟优化

- Web Speech 保持长连接，避免重复握手
- `interimResults: false`，减少无效处理
- LLM 调用期间显示 loading 动画
- 操作序列逐条执行，150ms 间隔，视觉上可见

### 3.3 错误处理

| 场景 | 处理 |
|------|------|
| STT 返回空 | TTS「没听清，请再说一遍」 |
| 连续 3 次低置信度 | TTS「网络似乎不太好，可以试试简短一点」 |
| LLM 超时 | 「正在处理上一个指令...」 |
| LLM 返回无效 JSON | 重试一次，仍失败则「这个指令我没理解，换个说法试试？」 |

## 4. NLU Agent 层（核心）

### 4.1 调用流程

```
用户指令文本
  ↓
组装 Context = 系统提示词 + 画布状态快照 + 最近 N 轮对话 + 当前指令
  ↓
LLM API 调用 → 结构化操作序列 JSON
  ↓
验证 & 执行 → 更新画布状态 → 状态写回下一轮 context
```

### 4.2 画布状态表示

紧凑 JSON 喂入 LLM context，每个元素有唯一 ID：

```json
{
  "elements": [
    {"id":"e1","type":"circle","cx":200,"cy":150,"r":60,"color":"#FF0000","fill":true},
    {"id":"e2","type":"rect","x":300,"y":200,"w":100,"h":80,"color":"#0000FF","fill":false}
  ],
  "canvas": {"width":800,"height":600,"bg":"#FFFFFF"}
}
```

### 4.3 系统提示词设计

1. **角色**: 语音绘图助手，将中文指令转为绘图操作
2. **操作集**: 声明所有操作及参数 schema
3. **输出格式**: `{"operations": [...], "reply": "确认语"}`
4. **引用规则**: 「它」「那个」「左边的」→ 根据状态+历史解析为 element ID
5. **复合分解**: 「画一个房子」→ 自动拆为 4-5 条原子操作
6. **模糊处理**: 「大一点」→ 比例放大 20%；指令不完整时推断意图
7. **容错**: 置信度低时 reply 中请求澄清

### 4.4 原子操作集

| 操作 | 参数 | 描述 |
|------|------|------|
| `create_shape` | type, x, y, w, h/r, color, fill | 创建图形 |
| `create_line` | points[{x,y}], color, width | 创建线段/路径 |
| `move` | target_id, dx, dy | 平移 |
| `resize` | target_id, scale_x, scale_y | 缩放 |
| `delete` | target_id | 删除元素 |
| `recolor` | target_id, color | 改色 |
| `clear` | — | 清空画布 |
| `undo` | — | 撤销 |
| `redo` | — | 重做 |
| `freehand` | points[{x,y}], color, width | 画笔路径 |

## 5. 绘图引擎

### 5.1 Canvas 与空间定位

- **Fabric.js**: 对象模型 + 序列化 + 交互态
- **九宫格定位**: 将画布划分为 3×3 逻辑区域，LLM 将「左上」「中间」「右下」等语义映射为坐标

```
┌──────────┬──────────┬──────────┐
│  左上     │   上      │  右上     │
├──────────┼──────────┼──────────┤
│  左       │  中间     │  右       │
├──────────┼──────────┼──────────┤
│  左下     │   下      │  右下     │
└──────────┴──────────┴──────────┘
```

- 「往右移一点」→ `dx += 40`
- 「放大一点」→ scale × 1.2

### 5.2 Freehand 模式

纯语音无法实时控制连续笔触移动（物理信号缺失）。支持路径描述式生成：

- 支持: 「从左上到右下画一条直线」「画 S 形曲线」「画心形」
- 不支持: 实时语音拖拽笔触（无指点设备，非工程问题）

### 5.3 视觉反馈

- 操作元素短暂高亮（黄色边框闪烁）
- 底部状态栏显示最后操作
- 操作序列逐条可见

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| LLM 延迟影响体验 | 操作序列返回后边执行边播 TTS，并行化感知 |
| Web Speech 中文不准 | 兜底云端 STT + 提示用户说标准普通话 |
| LLM 幻觉/错误坐标 | 坐标 clamp 到画布范围内，操作前 dry-run 验证 |
| Fabric.js undo 不内置 | 自行维护操作栈，记录每步逆向操作 |
| API key 暴露 | V1 比赛 demo 直调 API，使用环境变量注入 key；后续可加简单后端代理 |

### 9.2 未实现及原因

**实时语音笔触拖拽（1 项）**：语音信号无法提供连续的二维坐标流，物理上不可行。替代方案为路径描述式生成（「从A到B画线」「画S形曲线」），LLM 负责生成路径控制点。

### 9.3 实际技术栈

| 层 | 实际选型 | 说明 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite | 按设计执行 |
| Canvas | Fabric.js 6 | 按设计执行 |
| 语音识别 | Web Speech API + Whisper API 兜底 | 双通道实现，低置信度自动云端重识别 |
| NLU | OpenAI 兼容 API | 支持 GPT-4o / DeepSeek / 通义千问等 |
| TTS | Web Speech Synthesis API | 浏览器原生 |
| 撤销栈 | 自维护深拷贝栈 | 修复了浅拷贝导致撤销失效的 bug |
| 并发防护 | processingRef 互斥锁 | 防止快速语音指令冲突 |

### 9.4 与设计的偏差

| 偏差 | 说明 |
|------|------|
| `response_format: json_object` 已移除 | 提高非 OpenAI 提供商兼容性，靠 prompt 引导 JSON |
| 复合指令模板大幅扩展 | 从 3 个扩展到 20+ 个（城堡/花/车/船/火箭/雪人等） |
| 触屏撤销/重做按钮 | 超出设计范围，作为降级操作路径（语音识别失败时可用） |
| 低置信度连续警告 | 超出设计范围，连续 3 次低置信度自动提示 |
